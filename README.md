# ⚜️ Barath & Rithika | Premium 3D Interactive Wedding Invitation Website

A luxury, cinematic, and interactive digital Indian wedding invitation website crafted for **Chi. BARATH** and **Chi. Sou. RITHIKA**, celebrating the cultural heritage of Kasaragod, Kerala.

---

## ✨ Features & Experiences

1. **Cinematic 3D Entrance (Main Attraction)**:
   - Traditional Indian double wooden door in center carved with floral relief patterns, gold inlay, and brass studs.
   - Antique brass ring handles with realistic PBR specular highlights.
   - Hanging fresh white jasmine flower garlands (*Mullappoo mala*) and marigold torans.
   - Divine golden interior god-rays bursting forth when the doors swing open.
   - Smooth camera dolly and perspective parallax.
   - Auspicious temple bell chime sound effect upon opening.
   - Graceful CSS 3D fallback for devices without WebGL.

2. **Main Wedding Invitation Card**:
   - Luxurious cream parchment paper texture with gold zari double borders and antique corner filigrees.
   - Auspicious Deity blessing: `|| Shree Kuladevatha Prasanna ||`.
   - Sacred Ganesha emblem and brass oil lamps (*Diyas*) with animated flickering flames.
   - Exact names, family lineage, addresses, muhurtham timing, and contact phone number.
   - Interactive quick-actions: Call groom's parents, Share Invitation, and Print Card.

3. **Live Wedding Countdown**:
   - Real-time countdown to **Sunday, 22nd November 2026 at 11:05 AM IST**.
   - Glassmorphic ivory cards with gold borders and deep burgundy typography.
   - "Add to Google Calendar" 1-click event integration.

4. **Ceremony Details & Venue Map Navigation**:
   - **Muhurtham:** 11:05 AM to 12:23 PM.
   - **Venue:** Panjikola Sri Parthasarathi Seva Mandir, Panayal, Kasaragod, Kerala.
   - "Get Directions" link to Google Maps.
   - One-click "Copy Venue Address" button.
   - Feast highlights: Traditional Kerala Wedding Sadhya.

5. **Web Audio API Indian Wedding Classical Instrumental**:
   - Zero-dependency procedural synthesis of authentic Tanpura drone (Sa-Pa tuning in D) and serene Bansuri (bamboo flute) melodies in auspicious Raag Bhupali.
   - Auspicious temple bell (*Ghanta*) chime.
   - Floating music widget with animated sound equalizer bars, mute/unmute toggle, and volume control.

6. **Interactive Blessings Guestbook & Confetti**:
   - Closing quote: *"Your presence and blessings will make our special day even more memorable."*
   - Digital guestbook where family and friends can submit warm wishes.
   - Triggers a celebratory shower of gold & rose confetti upon submission.

7. **Visual Ambience & Physics**:
   - 60 FPS Canvas-based floating Jasmine blossoms (*Mullappoo*) and soft blush rose petals drifting across the page.
   - Respects user accessibility preferences (`prefers-reduced-motion`).

## 🚀 Getting Started

### 1. Development Server
```bash
npm install
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 2. Production Build
```bash
npm run build
npm run preview
```
The optimized static output is generated in the `dist/` directory, ready to deploy to any static host (Vercel, Netlify, Cloudflare Pages, GitHub Pages, Firebase).
